# RM65 KIT 参数化外壳（首版）

这是用于到货核对的**可调整原型**，不是已经过实物验证的生产模型。
当前以仓库尺寸图中的 KIT 名义板框 `152 × 109 mm` 为覆盖基准。

## 文件

- `rm65_kit_enclosure.scad`：上下壳、可替换接口挡板、可选天线孔。
- `export_stl.sh`：用 OpenSCAD 导出三件 STL 和 PNG 预览。
- `preview.html`：基于 Three.js 的本地交互预览，可看单件或装配。
- `server.py`：预览用本地 HTTP 服务。
- `build/`：已导出的 STL 和预览图。
  `rm65_kit_top_inner.png` 是顶壳内侧检查图，可核对 roof-side boss 与肋板。

## 使用

打开 `rm65_kit_enclosure.scad`，在文件顶部修改参数，将 `part` 设为
`"bottom"`、`"top"`、`"io_panel"` 或 `"assembly"`。命令行重新导出：

```sh
cd enclosure
./export_stl.sh
```

预览页复用了参考项目的 Three.js + `STLLoader` + `OrbitControls` 结构。
前端依赖从 unpkg CDN 加载，因此首次打开需要联网。启动：

```sh
cd enclosure
python3 server.py
```

再访问 `http://localhost:8080`。页面可切换底壳、顶壳、挡板和装配视图，
并可直接下载 STL。装配视图中的绿色/深色板卡、五根天线、接口块和紧固件
只是帮助理解整体形态的参数化占位件，**非打印、非实测，也不会写入 STL**。
默认合盖加载 `rm65_kit_top_assembly.stl`，它由 SCAD 原始装配坐标直接
导出，不再对打印方向顶壳做浏览器逆变换，也没有人为 Z 间隙。防闪烁只使用
渲染材质的 polygon offset，不改变壳体闭合位置。页面提供正视、侧视和
交缝近景预设。

## 到货后必须核对

1. PCB 实际长、宽、厚度、版本号及四角/中部安装孔坐标和孔径。
2. PCB 上下最高器件、散热片、焊脚和 BTB 堆叠高度。
3. RJ45、USB、电源、Reset、UART、LED 的中心坐标、高度和插拔包络。
4. 五个射频端口的频段映射、天线型号、接头直径、馈线长度及推荐净空。
5. 套件的**外部输入电压和极性**；模组的 3.3 V 要求不等于 KIT 输入。

建议先只打印底壳和接口挡板做装配核对。默认接口挡板是一个宽大的保守
服务口；白色框对应可打印的可替换挡板，不是已知网口位置。测量后再把
`io_openings` 改为各接口的独立开孔。默认生成五个
外置天线安装孔；确认接头后必须调整 `antenna_x`、`antenna_z` 和
`antenna_hole_diameter`，也可暂时关闭 `antenna_holes_enabled`。

KIT PcbDoc 可确认顶层有一排 9 个 `LED 3MM` 器件，约位于 PCB 左下基准
`x=15.01–64.34 mm, y=102.06 mm`：D5/D6/D8/D9/D10/D11/D13 为黄色封装，
D14/D15 为绿色封装。规格书还提供 5 个交换机端口、WAN TX/RX、2.4G/5G
Wi-Fi LED 信号。由于 LED 引脚弯折方向、实际露出高度、功能对应顺序和壳体
出光面尚未用实物确认，`led_windows_enabled` 默认关闭，模型不虚构灯孔。

PCB 固定已统一采用 M2：模型提供 2.3 mm 打印通孔、6 mm 螺柱及 1 mm 高
导向凸台。螺柱默认坐标只是依据名义板框的保守角部估计，必须更新
`pcb_holes`，并核对实际 PCB 孔径能否容纳导向凸台。

PCB 与外壳绝不共用螺钉。首版 BOM 分为：

- PCB 固定：M2 盘头螺钉 4 颗，从 PCB 上方锁入底壳专用 PCB boss；长度须按
  实测 PCB 厚度、垫片和 boss 有效牙深确定。
- 上下壳合盖：M2 沉头螺钉 4 颗，从外底面穿过底壳独立通孔柱，锁入顶壳
  1.7 mm 导孔 boss；长度须按最终壳高和有效啮合长度实测确定。

为让两套 boss 真正错开，`pcb_side_clearance` 默认增至 8 mm。名义 PCB
孔中心在壳体约 `(14.4,14.4)` 等四角，合盖孔中心在距壳边 8 mm 的四角，
两者不再像旧版那样几乎重合。
打印前还应按材料和打印机调整 `fit_clearance`，并在切片软件中检查壁厚、
悬垂、螺孔及模型单位（毫米）。

PCB 与上下壳固定均使用 M2。上下壳沿用参考项目的 2.3 mm 通孔、1.7 mm
导孔、5.0 mm 沉头直径、1.8 mm 沉头深度，以及 5.0 mm boss、7.5 mm
加强基座、2.5 mm 加强高度；本模型另为关键柱增加十字肋板。沉头螺钉从
底面装入，头部齐平或略低于底面。PCB boss 保留平整承托面，板内螺钉不做
沉头，以免缩小 PCB 支撑面。到货后仍需依据 PCB 厚度、螺柱高度和垫片确定
螺钉长度，并核对孔边元件净空。

底壳坐标中 `z=0` 是外底面。每个沉头孔在 `z=-0.1` 处为 5.0 mm 大口，
沿 `+z` 向壳内收窄到 2.3 mm，并另有贯穿底板与底壳 boss 的 2.3 mm
直通孔；M2 沉头螺钉从外底面插入后，螺头应齐平或略低，不会留下封闭薄膜。

上下壳 boss 不共用同一加固方向：底壳通孔柱终止于 `split_z-lid_overlap`；
顶壳导孔柱从该高度开始并一直连接到顶盖内表面。顶壳扩径区和定向肋只位于
靠顶盖的最后 2.5 mm，分别连接最近两面顶壳内壁，分型面一侧没有悬空肋，
上下柱也不会在搭接区互相穿插。

四个合盖沉头孔中心距壳边 8 mm，四个脚垫槽中心距壳边 30 mm；
二者包络独立，每个沉头孔均可直接从底面使用工具，不需要拆脚或穿过软脚。
若调整 `case_post_inset`、`bottom_foot_inset`、脚径或沉头直径，必须重新
检查两中心距离大于两者半径之和并额外保留工具摆动净空。

底壳不直接打印减震脚。四个槽为直径 11.0 mm、深 1.0 mm，入口轻微放宽
到 11.4 mm；独立 `rm65_kit_foot_pad.stl` 脚垫直径 11.2 mm、总高
3.2 mm，其中约 1.0 mm 压入槽内、2.2 mm 外露。末端缩到 10.8 mm 形成
FDM 友好的导入倒角，无内部倒扣。推荐用 TPU 95A 先打印 4 个；对准后用
平板均匀压入。若打印机挤出偏差较大，先单独试配并调整
`foot_pad_diameter`，不要强压导致底板开裂。

顶壳通风阵列上方带两行贯穿镂空粗体无衬线文字：`NORMAN` 与
`Router v1`。文字是顶壳 STL 的真实切孔，不是 HTML 贴图。为避免
`O/R/A/o` 的封闭字腔成为脱落孤岛，两行字高中部保留 1.0 mm 模板连桥；
字号、字体、位置与连桥宽度均可在 SCAD 顶部调整。默认文字与通风槽、壳边
保持独立材料带，不会和通风孔连成薄桥。
