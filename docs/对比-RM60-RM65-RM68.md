# HLK-RM60 / RM65 / RM68 对比

> 依据海凌科公开产品页与规格书摘要（非实验室实测）。信号最终仍取决于天线与固件。

## 一览

| 项目 | **RM60** | **RM65** | **RM68** |
|------|----------|----------|----------|
| 定位 | 入门 Wi‑Fi 6 路由模组 | 家用级 AX3000（联发科） | 家用级 AX3000（高通） |
| 芯片方案 | MT7621A + MT7905 + MT7975 | **MT7981B + MT7976C + MT7531A** | **IPQ5018 + QCA8337 + QCN6102** |
| Wi‑Fi 档位 | **AX1800**（约 573+1201 Mbps） | **AX3000**（574+2402 Mbps） | **AX3000**（574+2402 Mbps） |
| 5G 频宽 | 最高约 **80 MHz** | **160 MHz** | **160 MHz** |
| CPU | 双核 MIPS @ **880 MHz** | 双核 A53 @ **1.3 GHz** | 双核 A53 @ **1 GHz** + 12 线程网络协处理 |
| 内存 / Flash | **128 MB / 16 MB** | **256 MB / 128 MB NAND** | **256 MB / 128 MB NAND** |
| 网口 | 千兆 ×5 | 千兆 ×5~6，另有 **2.5G SGMII** 能力 | 千兆 ×6（1WAN+5LAN） |
| 外置 FEM | 常规方案 | 常规高性能 | 宣传 **外挂 4× FEM** |
| 供电 | 3.3V | 3.3V（建议 ≥5A） | **5V**（建议 ≥3.5A） |
| 工作温度 | 约 -20~60℃ | -20~80℃ | -20~80℃ |
| 软件 | OpenWrt | OpenWrt | OpenWrt |
| 尺寸 | 约 60×90 mm | 60×90 mm | 60×90 mm |

## 信号谁更强？

**标称无线能力：RM65 ≈ RM68 ≫ RM60。**

- RM60 是 AX1800，5G 无 160 MHz，天花板明显更低。  
- RM65 / RM68 同属 AX3000 + 160 MHz，理论峰值同级。  
- 规格书发射功率都在「家用路由」量级（约十几～二十多 dBm）；RM68 强调 4×FEM、RM65 2.4G 也可到 ~24 dBm 档——**纸面接近，实墙表现看天线与校准，不能只看型号判输赢**。  
- 若只比「模组射频档位」：**不要选 RM60 当主力覆盖**；RM65 与 RM68 同档，需实测。

## 算力 / 做分流小程序谁更合适？

| 维度 | 更强方 | 说明 |
|------|--------|------|
| CPU 主频与通用算力 | **RM65** | 1.3 GHz A53，跑 OpenWrt 用户态更宽裕 |
| 路由硬件卸载潜力 | RM68（若固件带齐 NSS）/ RM65（Filogic 生态） | 主线 OpenWrt 上高通 IPQ50xx 卸载常不完整 |
| Flash 装软件包 | **RM65 / RM68** | RM60 仅 16 MB Flash，自定义包很容易装不下 |
| 社区 OpenWrt 成熟度 | **通常 RM65（MT7981）更省心** | 联发科 Filogic 在 OpenWrt 上更常见；RM68 要盯厂商 SDK/卸载 |
| 2.5G 上行扩展 | **RM65** | 有 2.5G SGMII；RM68 规格以千兆口为主 |
| 与 KIT/资料 | 各有套件 | 你当前仓库已集中 RM68 资料 |

对「RM68 轻分流 + Mac 旁路分析」：**三款都能做用户态控 nft 规则**；更稳妥量产候选往往是 **RM65（生态）或 RM68（你已选型）**；RM60 仅适合验证概念，Flash/性能偏紧。

## 能力排序（综合）

```
家用 Wi‑Fi 吞吐/覆盖潜力：  RM65 ≈ RM68  >>  RM60
OpenWrt 二次开发省心度：    RM65  ≥  RM68  >>  RM60
内存/装包空间：              RM65 ≈ RM68  >>  RM60
性价比/入门：                RM60（但能力最弱）
```

**一句话：要信号和家用体验选 RM65 或 RM68（同档 AX3000）；RM60 明显低一档。RM65 更偏联发科生态与主频；RM68 更偏高通 + 外挂 FEM，适合你已开始的资料与 KIT 路线。**

## 对另一 AI「RM68 信号更强 / 工业宽温」说法的核对

| 说法 | 准确性 | 依据 |
|------|--------|------|
| 两者都是 AX3000，速率 574+2402 | ✅ 正确 | 双方规格一致 |
| RM68 = IPQ5018 + QCN6102，外挂 4×FEM | ✅ 正确 | RM68 规格书写明 |
| RM65 = MT7981B @ 1.3GHz，算力更强 | ✅ 大体正确 | 主频更高，跑插件更宽裕 |
| RM68 有 12 线程 NPU，高并发更稳 | ⚠️ **有条件** | 厂商 SDK/带 NSS 卸载时成立；**主线 OpenWrt 上 IPQ50xx 常缺完整 NSS**，优势可能消失 |
| RM65 是「内置功放」、极限功率必弱于 RM68 | ❌ **不准确** | 英文页亦提到 2.4/5G PA/LNA；RM65 标称 2.4G 可达 ~24.5dBm，RM68 规格约 +23dBm 档——**不能据此断定 RM68 信号必强** |
| RM68 工作温度 -40℃~85℃ 工业级 | ❌ **错误** | **规格书 V1.02：工作 -20℃~80℃**；-40~85 是**存储**温度。营销文案「宽温 -40~85」与规格书冲突，以规格书为准 |
| RM65 工作 -20~80℃ | ✅ 与公开页一致 | 与 RM68 **工作温区同档** |
| 供电 3.3V/5A vs 5V/3.5A | ✅ 正确 | 底板电源设计不同 |

**结论：另一 AI 的芯片与算力侧写大体可用；「RM68 信号必然更强」「工业级 -40℃ 工作」不可采信。选型不能只靠 FEM 叙事。**
